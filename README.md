## 🚀 What I've Been Working On

### ☁️ AWS DMS Monitoring Toolkit — Python & boto3

A collection of Python utilities to improve **visibility and troubleshooting for AWS Database Migration Service (DMS)** replication workloads.

- Monitor replication instances and tasks, including **CPU, available memory, swap, disk, and network throughput**.
- Analyze **Full Load and CDC** progress, replication latency, stalled tables, and task failures.
- Investigate errors using **Amazon CloudWatch metrics and logs**.
- Inspect table mappings, identify overlapping replication rules, and review task configuration.
- Build a **terminal-based daily health overview** with historical snapshots and trend comparisons.
- Support safer operational decisions through read-only diagnostics and documented recovery procedures.

**Stack:** `Python` · `boto3` · `AWS CLI` · `AWS DMS` · `CloudWatch` · `Redshift` · `MySQL` · `Linux/WSL`
